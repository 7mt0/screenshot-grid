# Screenshot Grid

A free, in-browser tool for putting episode screenshots into a clean grid: every frame whole and sharp, sorted by time in the episode, ready to post on X.

**Use it here:** https://7mt0.github.io/screenshot-grid/

- Suggests every layout for your number of screenshots (2 × 4, 4 × 2, 3 × 3…), tall or wide.
- Sorts frames by the time in their file names (e.g. `…mkv_snapshot_19.33.762`), and you can still drag them anywhere.
- Removes black bars, zoom into any frame, swap or replace frames.
- Exports at the largest size X keeps (4096 px), or copy it straight to the clipboard.
- Everything runs in your browser. Your screenshots are never uploaded.
